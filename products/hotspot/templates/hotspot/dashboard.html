                        Install

                        Four steps. The first visit shows up in the dashboard a few seconds after step 2.

                        1

                        Lock the server down

                        Set these two values in the environment of the server running Hotspot, in .env.hotspot for the full stack or next to the standalone command. The key goes in the script tag below, so only your site can send data. The password protects this dashboard.

                        Both values were generated in this browser just now and exist nowhere else. Restart the server after setting them.

                        2

                        Add the script to your site

                        Paste this tag into the <head> of every page, before your other scripts. That is the whole install: page views, clicks, rage clicks, errors, web vitals and session replay all come from this one line.

                        <script src="{{ sdk_url }}" data-api-key="{{ api_key }}" defer></script>
                        3

                        Check that data arrives

                        Open your site in another tab and click around. This box turns green when the first session reaches this server.

                        4

                        Optional: names and goals

                        Tell Hotspot who a visitor is after they sign in, so sessions show a name instead of "Visitor 4a8b2c". Then name the events that count as a goal, so the funnel and the conversion rate mean something to you.

                        Script options
                        data-api-key
                        The key sent with every event. Required.
                        data-api-host
                        Where events are sent. Defaults to the host the script came from.
                        data-autocapture="false"
                        Turn off click and form capture.
                        data-capture-errors="false"
                        Turn off JavaScript error capture.
                        data-capture-pageview="false"
                        Turn off automatic page views.
                        data-replay="false"
                        Turn off the session recording. The event timeline still works.
                        data-mask-inputs="all"
                        Mask every typed value in the recording. Password and payment fields are always masked.
                        data-mask-text="true"
                        Mask all text on the page in the recording.
                        data-capture-console="false"
                        Leave console output out of the recording.
                        data-capture-network="false"
                        Leave network requests out of the recording.
                        data-capture-web-vitals="false"
                        Turn off web vitals.
                        data-debug="true"
                        Log every captured event to the browser console.
                        data-debug-hud="true"
                        Show an on-page overlay of your own clicks. Toggle it with Alt+H, or add ?hotspot_debug_hud=1 to a URL.
                        data-hotspot-mask
                        On any element: mask its text and typed values in the recording.
                        data-hotspot-block
                        On any element: replace it with an empty box of the same size in the recording.
                        JavaScript API (window.hotspot)
                        • capture(name, props)Record a custom event
                        • identify(id, { email, name, company })Attach a person to the visitor
                        • setPersonProperties(props)Update person properties
                        • register(props)Send these properties with every event
                        • reset()Forget the visitor and start a new session
                        • optOut() optIn() hasOptedOut()Visitor consent
                        • startSessionRecording() stopSessionRecording()Replay on and off, for consent flows
                        • getDistinctId() getSessionId()Current ids
                        • on(eventName, callback)Run code when an event is captured
                        • flush()Send queued events now
                        • debug.show() debug.hide()Toggle the on-page overlay
