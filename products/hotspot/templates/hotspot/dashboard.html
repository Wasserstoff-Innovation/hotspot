        Install

        One script tag records everything the dashboard shows.

        Script tag

        <script src="{{ sdk_url }}" data-api-key="{{ api_key }}" defer></script>

        Add it to the <head> of every page. It records page views (including single-page-app route changes), clicks, rage clicks, dead clicks, scroll depth, form submits, JavaScript errors and web vitals, plus a replay of each session with its console output and network requests.

        Typed values show up in the replay unless the field is masked. Password and payment fields are always masked; add data-hotspot-mask to anything else.

        Call window.hotspot.identify(userId, { email, name }) after sign-in to see people instead of visitor ids.

        Script attributes

        data-api-key
        The key sent with every event. Required.
        data-api-host
        Where events are sent. Defaults to the host the script came from.
        data-autocapture="false"
        Turn off click and form capture.
        data-capture-errors="false"
        Turn off JavaScript error capture.
        data-capture-pageview="false"
        Turn off automatic page views.
        data-debug="true"
        Log every captured event to the browser console.
        data-debug-hud="true"
        Show an on-page overlay of your own clicks. Toggle it with Alt+H, or add ?hotspot_debug_hud=1 to a URL.
        data-replay="false"
        Turn off the session recording. The event timeline still works.
        data-mask-inputs="all"
        Mask every typed value in the recording.
        data-mask-text="true"
        Mask all text on the page in the recording.
        data-capture-console="false"
        Leave console output out of the recording.
        data-capture-network="false"
        Leave network requests out of the recording.
        data-capture-web-vitals="false"
        Turn off web vitals.
        data-hotspot-mask
        On any element: mask its text and typed values in the recording.
        data-hotspot-block
        On any element: replace it with an empty box of the same size in the recording.

        JavaScript API

        window.hotspot
        • capture(name, props)Record a custom event
        • identify(id, { email, name, company })Attach a person to the visitor
        • setPersonProperties(props)Update person properties
        • register(props)Send these properties with every event
        • reset()Forget the visitor and start a new session
        • optOut() optIn() hasOptedOut()Visitor consent
        • getDistinctId() getSessionId()Current ids
        • on(eventName, callback)Run code when an event is captured
        • flush()Send queued events now
        • debug.show() debug.hide()Toggle the on-page overlay
