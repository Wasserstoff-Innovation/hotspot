Got Questions?

Frequently Asked Questions

Do I need to be a developer to use Hotspot?

No! Hotspot was designed specifically for store owners, marketers, and founders. You don't write complex code or configure tags. You simply paste one line or connect via Shopify, and Hotspot presents everything in plain English with a 0–100 score.

How is this different from Google Analytics 4?

Google Analytics shows you raw numbers (e.g. "traffic dropped 20% on /checkout"), but doesn't explain why. Hotspot identifies the exact physical reason—such as an unhandled button error or a button below the mobile fold—and gives you a ranked fix list.

How do the 1-click AI fix prompts work?

When Hotspot finds a bottleneck, it writes a clear, hallucination-free prompt with the exact file target, CSS selector, and error context. You simply copy and paste that prompt into Cursor, Claude Code, or Lovable, and your AI updates your code automatically.

Will Hotspot slow down my website or store?

No. Hotspot is 3.8KB gzip and runs entirely off the main thread using passive listeners and background sendBeacon dispatching, ensuring 0ms blocking time and zero impact on your Core Web Vitals.
