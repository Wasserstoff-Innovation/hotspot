05 // FREQUENTLY ASKED QUESTIONS

Engineered for zero friction, complete privacy, and instant AI execution.

Direct factual answers to technical, operational, and commercial questions about hotspot.js.

Q1. How does hotspot.js achieve 0-config tracking without track() calls?

hotspot.js installs directly into the browser DOM runtime via a single 3.8KB script tag. It hooks into the Navigation API, History pushState, PointerEvents, and DOM MutationObserver. Every route transition, click vector, rage-tap cluster (>3 taps in 800ms), and Core Web Vital is automatically indexed without writing manual analytics tags.

Q2. Why is Telemetry Core free forever ($0)?

Baseline product tracking, route funnels, and click heatmaps should be open infrastructure, not an expensive metered utility. Telemetry Core is $0 forever. We monetize only on the $9/mo automated Intelligence layer, which runs advanced cross-signal synthesis between Google Search Console intent and in-app DOM state to generate ready-to-paste AI fix prompts.

Q3. How does Hotspot join Google Search Console queries with live in-app DOM telemetry?

By linking your Google Search Console query stream via OAuth or API sync, Hotspot maps the exact keyword that generated a session with the user's immediate in-browser behavioral chain. This reveals critical friction like high-intent search queries bouncing within seconds because hero buttons open unexpected registration walls.

Q4. How do the 1-click AI prompts for Cursor and Claude Code work?

When Hotspot synthesizes a conversion bottleneck, it pinpoints the exact DOM selector, file route, error stack trace, and user reproduction steps. It compiles these into an authoritative, hallucination-free prompt with strict acceptance criteria that you copy directly into Cursor, Claude Code, or Lovable to fix the problem in minutes.

Q5. Is hotspot.js cookie-less, GDPR, and CCPA compliant?

Yes. hotspot.js uses ephemeral browser session storage and cryptographic hashes instead of persistent third-party tracking cookies. It does not record personal identity data (PII) without explicit consent, automatically redacts password and credit card inputs, and is fully GDPR, CCPA, and PECR compliant out of the box.

Q6. Does hotspot.js slow down page load or degrade Core Web Vitals?

No. hotspot.js is 3.8KB gzip and runs entirely off the critical rendering path. It uses requestIdleCallback, passive event listeners, and navigator.sendBeacon to batch payloads asynchronously with 0ms DOM blocking time, ensuring flawless Lighthouse scores and optimal Interaction to Next Paint (INP).
