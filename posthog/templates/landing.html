Built for visual clarity

Everything captured automatically. No analytics background required.

Click heatmaps

See exactly where users click and tap on every page. High-density visual clusters show what captures attention.

Rage click alerts

Detects rapid, repeated clicks on unresponsive elements. Instantly spots UI components your AI forgot to link.

Dead click detection

Flags non-interactive elements that users treat as links. The most common silent bug in generated frontend code.

Full autocapture

Every page view, button click, and form interaction is captured with full context. No manual tracking code needed.

100% Self-hosted

Runs on your own machine or private Docker instance. No cookie consent banners, no third-party tracking, no surprise bills.

Retroactive funnels

Build conversion funnels after you release features. Because all data is captured upfront, historical analysis is instant.
